# CityRoute

Сайт для подбора городских пеших маршрутов.

**Открыть сайт:** https://cityroute-walk-map.gbfksjhxmm.chatgpt.site

## Исходный код

[Скачать полный проект — CityRoute-source.zip](./CityRoute-source.zip)

Архив содержит 144 файла текущей версии проекта: страницы сайта, стили, JavaScript, серверную часть, миграции базы данных, тесты и настройки сборки. Для работы с кодом распакуйте папку `CityRoute`.

## Возможности

- Подбор маршрута по интересам, бюджету и компании.
- Карта и точки маршрута.
- Страницы маршрутов, прогулок и друзей.
- Светлая и тёмная темы.

## Запуск

Подробности находятся в `README.md` внутри архива. Требуется Node.js версии 22.13.0 или новее. Версия pnpm указана в `package.json`.

```sh
npm run install:ci
npm run dev
```

Авторизация через ChatGPT и серверные функции используют инфраструктуру исходного хостинга. Для переноса на другой хостинг потребуется отдельно настроить авторизацию и базу данных. GitHub Pages не запускает эту серверную часть.

Файлы `GOOGLE_SETUP.md` и `YANDEX_SETUP.md` описывают настройку карт. Google Maps API key в исходниках не задан.
